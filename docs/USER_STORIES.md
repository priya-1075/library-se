# User Stories

US1: As a librarian, I want to add a book with ID, title, and author so that the library can store book details.
US2: As a librarian, I want to borrow a book so that I can mark it as borrowed.
US3: As a librarian, I want to return a book so that it becomes available again.
US4: As a librarian, I want to generate a report so that I can see the status of all books.
